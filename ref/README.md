# DBExec-UI — `ref/` reference library

Context files for anyone (human or agent) working in this repo. Read
`../CLAUDE.md` first for the FE engineering contract, then these:

- **[PRODUCT.md](PRODUCT.md)** — what DBExec is, the four pillars, who uses
  it, architecture at a glance, roadmap. (Same file lives in the API repo's
  `ref/`.)
- **[MODULE-MAP.md](MODULE-MAP.md)** — every FE feature module, its landing
  route, and what it does.
- **[UI-CONVENTIONS.md](UI-CONVENTIONS.md)** — the design system: tokens
  (color / type scale / spacing / radius), the shared `app-custom-*`
  component kit, screen/form structure, i18n, state/loading discipline.

For the backend contract (endpoints, tenancy, entities), see
`../../DBExec-API/CLAUDE.md` and `../../DBExec-API/ref/`.
