Authoring redesign · the page users land on most

From four cramped rails to a real four-zone analysis studio.

The Analyses editor is where people spend their time. Today the canvas is starved by four stacked left rails, the config panel occludes the chart, data-state changes are silent, and building a first chart is invisible. This mockup shows the proposed layout on DBExec's own tokens — every function visible — beside today's. Draft-until-Save, per-tab visuals, and the Add-visual fix are already shipped; this is the shell + depth on top.

Everything the module will do

production-ready target

The full functional surface, grouped. shipped = landed this pass · to build = in the production plan. Chart types, data types, and aggregations are being researched exhaustively across Tableau, Power BI, Looker, Metabase, Superset, Hex & Sigma before build.

▊Chart types to build: gaps

  • Have (24): bar/line/area/combo, pie/donut/funnel/treemap/sunburst, scatter/bubble/histogram/box, gauge/radar/heatmap, sankey/waterfall/candlestick, KPI/number, table/pivot.
  • Adding: map/geo (choropleth, point, bubble, heat), bullet, lollipop, streamgraph, marimekko, calendar-heatmap, network, violin/ridgeline.
  • Field-aware picker — invalid types greyed for current fields.

#Data types to build

  • Numeric — int/float/decimal, currency, percent, scientific; locale format tokens.
  • Temporal — date/datetime/time, timezone, relative & fiscal periods, date-part hierarchy (Y/Q/M/W/D/H).
  • Categorical — nominal/ordinal, high-cardinality + "other" bucketing.
  • Geo (lat/long, country/region/postal, geojson), boolean, JSON/nested, robust null/NaN handling.

ΣAggregations to build: FE+BE

  • Basic — sum/avg/min/max/count/count-distinct/median most shipped
  • Statistical — stddev/variance, percentile/quantile, mode, geo/harmonic mean.
  • Table-calcs — running total, moving avg, rank, % of total, difference, index, lag/lead.
  • Time-intelligence — YoY/MoM/QoQ, YTD/MTD, same-period-last-year, rolling N.
  • LOD — FIXED/INCLUDE/EXCLUDE-style; grand + subtotals for pivots. Dialect-aware SQL.

⚙Config & encoding to build

  • Channels: x/y, color, size, shape, detail, tooltip, label, row/col facets, dual axis.
  • Per-series color/type/axis, stacking modes, data labels, reference lines/bands, trend/forecast.
  • Palette swatches + per-value + conditional color; number/date format with live preview.
  • Sort + Top-N + "other"; small multiples; drill hierarchies.

⤢Interaction to build

  • Unified cross-filter (source→target) + active-filter chips.
  • Drill-down (hierarchy) & drill-through (to detail); tooltip hover-sync.
  • Brush/zoom/pan, legend toggle, click-to-filter.
  • Parameters (single/multi/range/date) + what-if + dynamic axis/measure swap.

🗂Authoring UX core shipped

  • Draft-until-Save — everything in-memory, one atomic Save done
  • Tabs: menu/drag/rename/color/overflow; per-tab visuals done
  • Add-visual works while data loads done
  • To build: 4-zone shell, Build/Format rail, empty-state onboarding (①②③ + sample data), command palette, undo/redo, duplicate-analysis, comments.

⚡Data scale & correctness to build: BE

  • Server-side aggregation pushdown; transparent Top-N / row-limit banners.
  • Table virtual scroll; scatter/line downsampling (LTTB).
  • Timezone + fiscal-calendar correctness; approximate percentile/count-distinct at scale.
  • Framed empty / error / loading states; export CSV/Excel/PDF/PNG.

♿A11y & polish to build

  • Keyboard nav across tabs/canvas/panels; visible focus; ARIA roles.
  • Micro-interactions: drag affordances, eased transitions, save/dirty indicator.
  • Colorblind-safe palettes; token-driven contrast; consistent iconography.
